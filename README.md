A superpower so pointless that naming it is the whole joke. The entry is one line, 75 characters, written to `/output/entry.txt` by `main.py`:

`I can summon any object in the world, but only if it is already in my hand.`

## How the line was picked

Twelve hand-drafted candidates were graded against the judge's brief — useless first, funny second, unexpected third, then tight and clear — and the highest score won, ties going to the shorter line. The winner scores 47 and cannot help at all: summoning only what you already hold.

## Running it

Run it from the repo root:

    python3 ./main.py

The program checks the gate (1–140 characters, a single line), writes the entry, then reads it back and refuses to pass a mismatch.
